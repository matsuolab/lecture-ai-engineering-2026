## 宿題

- 取り組んだレベル：基礎
- やったこと：既定の stdio 設定で `uv run python -m app.agent --mcp --list-tools` を実行した後、サーバーを `uv run python -m app.mcp_server --http` で起動し、`glossary` の設定を `{"url": "http://127.0.0.1:8000/mcp"}` に替えて同じ一覧コマンドを実行した。
- 結果：
  - stdio では MCP クライアントがサーバーを子プロセスとして起動し、標準入出力で通信する。
  - Streamable HTTP ではサーバープロセスが `http://127.0.0.1:8000/mcp` で待ち受け、クライアントは URL へ接続する。クライアントを終了してもサーバーは別途停止するまで動作する。
  - どちらの接続でも、`--list-tools` には `glossary_search_glossary` と同じ引数 `query` が表示された。docstring を書き換えると、一覧のツール説明も書き換え後の文面に変わった。名前・引数・実装は変化しない。
- 気づき・疑問：docstring はモデルに渡すツール説明なので、どの質問でツールが選ばれるかに影響しうるが、実行そのものを強制する設定ではない。
