# 第5回 宿題「基礎」のレポート

## 1. 変更した内容
- `app/agent.py` 内のプロンプト（`INSTRUCTIONS`）を変更し、エージェントへの指示を追加
- （※実際に変更した内容を簡単に一言で書く。例：「学習支援のトーンに関する指示を追加した」など）

## 2. 変更前後の比較・挙動の違い
- **変更前:** 
  - 質問に対して、用語集の検索ツール（`search_glossary`）や講義要約ツールを使いながら標準的な回答を生成していた。
- **変更後:** 
  - プロンプトの変更に伴い、エージェントの回答の口調やトーン（または出力の構成）に変化が見られた。

## 3. 気づき・考察
- プロンプト（指示文）をわずか1か所書き換えるだけで、LLMの出力やツールの活用方針をコントロールできることを確認できた。
- Pythonファイル内では全角文字（句読点や括弧など）が構文エラー（SyntaxError）の原因になるため、半角英数字で記述する必要がある点に注意が必要だと学んだ。
