# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：第１回の素のLLMはこの講座のことではなく一般的でそれとない回答をしたが、エージェントでツールを呼び出して回答することでこの講座のことを理解した上で回答した。
- `--trace` で見えたツール呼び出し（ツール名と引数）：(tool call]   search_glossary({'query': 'LoRA'})
- 1つの質問での LLM 呼び出し回数（`requests`）：２回
- 追加したツールと、docstring に書いた説明：関数 make_quiz(lecture: int) -> str を追加。指定した回の用語集から確認問題として問題を出して欲しい。「第４回の確認問題出して」と言われた時に使用する。

## 宿題

- 取り組んだレベル：基礎
- やったこと：`app/agent.py` の `INSTRUCTIONS` から「必ず search_glossary で用語集を確認する」の行を削除し、同じ質問 `LoRAとは？` を `uv run python -m app.agent --trace "LoRAとは？"` で実行した。
- 結果：変更後も `search_glossary({'query': 'LoRA'})` が1回呼ばれ、LLM の呼び出し回数は2回だった。回答は用語集の内容に沿って LoRA の仕組みと特徴を説明し、第2回と示した。
- 気づき・疑問：検索を必須にする行を消しても検索が呼ばれた。`search_glossary` の docstring に、AIエンジニアリング用語に答える前に使うことが書かれているため、ツールの説明もモデルの選択に影響したと考えられる。
