# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：素のLLM（ツールなし）では、講座独自の細かい用語や第何回で扱ったかなどの正確な情報を知らず、一般的なシラスの内容でそれらしく推測して回答した。一方、エージェントではツール（用語集検索など）を使って正確な情報を取得してから回答するため、事実に基づいた正確な答えが得られた。
- `--trace` で見えたツール呼び出し（ツール名と引数）：`search_glossary`（引数: `query="第1回"` や質問に含まれるキーワード）が呼び出されているログを確認できた。
- 1つの質問での LLM 呼び出し回数（`requests`）：2回（ユーザーの質問を受けてツールを呼ぶ判断をした段階で1回、ツールの返り値を受け取って最終的な回答を生成する段階で1回）
- 追加したツールと、docstring に書いた説明：（※今回は「基礎」のため未記入、または「基礎レベルのため追加なし」と記載

## 宿題

- 取り組んだレベル：基礎 
- やったこと：`app/agent.py` の `INSTRUCTIONS` を一部変更（「必ず search_glossary で用語集を確認する」という指示を削除）し、変更前後の挙動の変化を確認した。
  - 実行コマンド: `uv run python -m app.ask "第1回の講義内容について教えて"`

- 結果：変更前は `search_glossary` ツールが自動で呼ばれて正確な情報を引けていたが、指示を削除した変更後ではツールが呼ばれず、エージェント自身の知識のみで回答が生成されるようになった。
- 気づき・疑問：プロンプト（INSTRUCTIONS）における「必ずツールを使う」といった指示が、エージェントの行動やツールの選択に非常に大きな影響を与えていることがよく分かった
