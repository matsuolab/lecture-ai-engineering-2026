## 演習

- 第1回（素のLLM）とエージェントの回答の違い：第1回の回答とはまだ比較していない。今回のエージェントでは、回答前に用語集を検索し、取得した定義に基づいて説明することを確認した。また、回答の最後に関連する回が示された。
- `--trace` で見えたツール呼び出し（ツール名と引数）：「LoRAとQLoRAの違いは？」では、search_glossary({'query': 'LoRA'}) と search_glossary({'query': 'QLoRA'}) が呼ばれた。
「第2回の内容から確認問題を1問出して」では、make_quiz({'lecture': 2}) が呼ばれた。
- 1つの質問での LLM 呼び出し回数（`requests`）：どちらの質問も requests=2 だった。
- 追加したツールと、docstring に書いた説明：make_quiz(lecture: int) -> str を追加した。指定された回の用語を用語集から集め、ランダムに1つ選び、問題と答えをJSON文字列で返す。用語が見つからない場合の処理も追加した。
docstring には「指定された回の確認問題を求められたときに使う。用語集から用語を1つ選び、問題と答えを返す。」と記載した。
動作確認では第2回のPEFTについて出題され、uv run pytest -q は15件すべて成功した。
