## 宿題

- 取り組んだレベル：基礎

　やったこと：- `app/agent.py` の `INSTRUCTIONS` から、全体への指示である**「- 用語や講座に固有のことを答える前に、必ず search_glossary で用語集を確認する。」**の行をあえて削除し、モデルの挙動がどう変化するかを検証した。
　変更前後での違いを確かめるため、同じ質問で `--trace` 付きのコマンドを実行した。
  ```bash
  uv run python -m app.agent --trace "AIE2026の講座の宿題にある「3レベル」とは何ですか?"

- 結果：INSTRUCTIONS から検索を強制する指示文を削除した状態で実行したにもかかわらず、依然として search_glossary が自動で呼び出されていた（requests=2, tool_calls=1）。

- 気づき・疑問：INSTRUCTIONS から明示的な指示を消してもツールが呼ばれていた。要因として考えたのは、各ツールの docstringに、すでにツールの役割や使い所が詳細に記述されているためではないかと思う。そのため、モデル自身が考えて、この質問にはsearch_glossaryが必要ではないかと判断して選び取っているようだ。プロンプトの指示とツールの説明文（docstring）の相互作用について学ぶことができた。
