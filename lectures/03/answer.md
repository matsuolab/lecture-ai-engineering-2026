# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：第1回の素のLLMは講座の用語集を参照できないため、「宿題の3レベル」の説明が不正確になる可能性がある。エージェントは用語集を検索してから答えるので、講座で定めた説明に沿って回答できる。
- `--trace` で見えたツール呼び出し（ツール名と引数）：search_glossaryとquery=3レベル
- 1つの質問での LLM 呼び出し回数（`requests`）：2
- 追加したツールと、docstring に書いた説明：make_quiz(lecture)。docstring には、確認問題を求められたときに指定回の用語から1つ選び、「用語の意味は？」という問題と定義を返す、と記載した。

## 宿題

- 取り組んだレベル：基礎 / 実装 / 発展
基礎
- やったこと：`app/agent.py` の INSTRUCTIONS を「用語や講座に固有のことも、search_glossary を使わずモデルの知識だけで回答する」に変更し、「AIE2026の講座の宿題にある『3レベル』とは何ですか？」を変更前後に `--trace` 付きで実行した。同じ質問を `app.ask` にも入力して、素のLLMの回答と比べた。
- 結果：素のLLMは一般的な難易度分類を推測し、具体的な内容や提出ルールは講座資料で確認するよう回答した。エージェントは用語集に基づき、「基礎・実装・発展」の3段階でどれか1つに取り組めばよいと回答した。INSTRUCTIONS変更後も `search_glossary({'query': '3レベル'})` が呼ばれ、変更前後とも `requests=2`、`tool_calls=1` だった。
- 気づき・疑問：INSTRUCTIONSで検索しないよう指示しても、search_glossaryのdocstringが用語や講座固有の質問に使うよう説明し、他の指示にも用語集への言及が残っていたため、検索呼び出しは変わらなかった。ツールのdocstringや他の指示も、モデルがツールを選ぶ判断に影響する。
