## 宿題

- 取り組んだレベル：基礎

- やったこと：

  `app/tools.py` の `search_glossary` の docstring を変更した。

  変更前は「query には調べたい用語を1つだけ入れる」という説明だったが、「query には関連する用語をまとめて入れる」という説明に変更した。

- 結果：

  変更前は LoRA と QLoRA が個別に検索され、`search_glossary` が2回呼び出された（`tool_calls=2`、`requests=2`）。

  変更後は「LoRA QLoRA」という1つの query でまとめて検索され、`search_glossary` の呼び出しが1回になった（`tool_calls=1`、`requests=2`）。

  また、検索結果を直接確認したところ、LoRA と QLoRA の両方の定義が取得できていた。エージェントの回答でも両者の違いが説明され、関係する回として第2回が示された。

- 気づき・疑問：

  ツールの docstring を変更することで、LLMのツールの呼び出し方や引数が変化することが分かった。

  関連用語をまとめて検索することで、ツールの呼び出し回数は2回から1回に減少した。一方、LLMの呼び出し回数（`requests`）は2回のままだった。

  このことから、ツールの呼び出し回数とLLMの呼び出し回数は必ずしも一致しないことが分かった。
