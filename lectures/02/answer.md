## 宿題

- 取り組んだレベル：基礎
- 変えた設定やデータ：lora_rの値を16から32へ変更する前と後での、format_rate・content_rate・最終 loss・学習時間の変化を観察した。また、result.jsonを比較した。
- 結果（比較表や数字）：
変更前：`format_rate` = 1.0　 / `content_rate` = 0.904 / 最終loss = 0.013918 / 学習時間 = 236秒
変更後：`format_rate` = 1.0　 / `content_rate` = 0.904 / 最終loss = 0.015067 / 学習時間 = 242秒
変更前と後でほとんど変化がないことがわかる。最終lossが変更後の方が少し大きいのはパラメータが増えたことに起因していると考えられる。
2つのresult.jsonを比較すると、lora_rを16から32へ変更したことから変わった点はほとんどなかった。学習前の評価にかかった時間が10秒増え、学習後の評価にかかった時間が10秒減ったという変化はあったが、学習前のモデルは同じで、学習後のモデルは大きくなっているはずなので誤差の範囲だと考える。

- 変えた設定やデータ：FAQ・GROUNDED・UNGROUNDED を「卒論」をテーマにして置き換えて学習し、学習前後を比べた。「根拠なし」の質問はFAQに記載していないところを考えて手動で作成した。
- 結果（比較表や数字）：
学習前：`format_rate` = 0.053　 / `content_rate` = 0.000 / 
学習後：`format_rate` = 1.000　 / `content_rate` = 0.947 / 
推測すればギリギリ答えられそうな質問を「確認が不要」と断言して出力してしまった点以外、全て正しく答えられるようになった。出力形式は100%正しく出力できるように進化した。
