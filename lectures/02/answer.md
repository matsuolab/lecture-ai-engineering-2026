## 演習

- 使ったモデル・設定（`result.json` の `config` から）：
  ベースモデルとして Qwen/Qwen3.5-0.8B を使用し、エポック数 20、学習率 0.0002、LoRA rank 12、alpha 8 の設定で学習を実施した。
- 自分で学習を実行したか（`executed_training_myself`）：はい
- 学習前：`format_rate` = 0.0 / `content_rate` = 0.0
- 学習後：`format_rate` = 1.0 / `content_rate` = 0.727
- 退行した質問：なし（0件）
- 学習後に残った失敗と、その型：
  評価データを通じて検証した結果、フォーマットエラー（形式の崩れ）やハルシネーション（根拠なしの質問への断定）、過剰な拒絶はいずれも解消されており、学習による性能の劣化や特筆すべき失敗は確認されなかった。
- 知識を問う質問（セクション 6）の結果（学習前の分類 → 学習後の分類）と気づいたこと：
  学習前はすべての質問でフォーマットエラーとなり、未知の質問に対しても適切に処理できていなかった。しかし学習後は、用語集にある質問に対しては正確な定義と指定されたJSONフォーマット（`needs_review: false`）で回答できるようになり、一方で未知の質問に対しては `needs_review: true` を付与して「記載がありません」と安全に未記載判定を行えるようになった。この結果から、わずか数回のLoRA学習であっても、出力フォーマットの強制だけでなく「知らない情報をハルシネーションさせずに安全に拒絶する制御能力」まで学習させられる点に非常に大きな魅力を感じた。
- 学習で変わったこと・変わらなかったこと：
  指定されたJSONフォーマットの遵守率が劇的に向上し、未知の質問への安全な拒絶ができるようになった一方で、ベースモデルが本来持っている自然言語の基本的な生成能力や流暢さはしっかりと維持された。

## 宿題

- 取り組んだレベル：発展
- 変えた設定やデータ：
  発展課題の指示に沿って、`uv run python scripts/make_sft_dataset.py > glossary_sft.jsonl` を実行して作成したSFT用データセットで学習を実施した[cite: 1]。また評価データについても用語集に合わせて自分で作り直し、「LLMとは何ですか？」「プロンプトとは何ですか？」といった正解の定義が存在する質問と、「Gitとは何ですか？」「データベースとは何ですか？」といった用語集に記載のない未知の質問を具体的に設定して評価を行った[cite: 1]。
- 結果（比較表や数字）：
  学習前（before）の評価では `format_rate: 0.0` および `content_rate: 0.0` であったが、学習後（after）の評価では `format_rate: 1.0`、`content_rate: 0.727`、`both_rate: 0.727` へと劇的な改善を達成し、実行時間も約47秒で完了した。
- ファインチューニングが向く場面・向かない場面についての考察：
  今回の演習や宿題を踏まえて、LoRAを使った数分の学習でフォーマットの遵守率が100％に向上し、未知の質問に対してもハルシネーションを起こさず安全に「要確認」と判定できたことから、ファインチューニングは出力に対して厳格なルールやフォーマットが存在する場面に非常に向いていると考察できる。一方で、学習データに含まれない最新情報を臨機応変に出力させることには向いておらず、情報更新の多い領域ではRAG等の外部知識参照技術を組み合わせることが不可欠であると感じた。
