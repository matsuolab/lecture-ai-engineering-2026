## 宿題

- 取り組んだレベル：基礎
- やったこと：
  同じ質問を、temperature を 0.0 と 1.5 の2通りで3回ずつ実行して比べた（モデルは gemini-3.5-flash-lite 固定）。質問は、講座固有の「宿題の3レベルとは？」と、一般的な「LoRAとは何ですか？」の2つ。temperature は `generate_content` の `config=types.GenerateContentConfig(temperature=...)` で指定した。
- 結果：
  - 「3レベル」：6回とも「難易度別の3段階（初級・中級・上級／基礎・応用・発展）」という一般論で、実際の「基礎・実装・発展、どれか1つで完了」とは異なった。temperature 0.0 の3回でも、書き出しや構成、文字数（1447／1526／1032字）が毎回違った。temperature 1.5 は 1235／849／955字で、「具体的なカリキュラムにはアクセスできませんが」と断る回（1.5 の3回目）もあれば、断らずに断定的に書き出す回もあった。
  - 「LoRA」：6回とも Low-Rank Adaptation の略で、本体を固定して追加部分だけ学習する効率的なファインチューニング手法、という中身は一致した。違いは言い回しやたとえ（付箋など）、見出し構成、文字数（0.0：1062／1275／1289字、1.5：1103／1167／1321字）程度だった。
- 気づき・疑問：
  - temperature 0 でも出力は同一にならなかった。0 は「決定的」ではなく「ばらつきが小さい」くらいに考えるべきだと分かった。この実験では 0.0 と 1.5 の文字数の差もはっきりしなかったので、3回では傾向までは言えない。
  - 事実が安定している質問（LoRA）は温度を変えても結論が揃い、知識がない質問（3レベル）は毎回「それらしい一般論」を作る。回答が揺れないことと正しいことは別で、6回とも同じ方向に外れていた。
  - 同じ質問を何度か投げて答えが揃っても、それだけでは正しさの根拠にならない。講座固有の情報は用語集など外部の情報源を渡す必要がある（次回以降の課題だと思う）。
  - 疑問：temperature を最大に近い値にしたとき、どこから内容が崩れ始めるのか。
