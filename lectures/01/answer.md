# 第1回 解答

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：基礎・実装・発展の3段階があり、どれか1つに取り組めば宿題を完了できる。
- 用語集の正しい意味と比べて気づいたこと：素のLLMには用語集が渡されないため、講座固有の内容を正確に答えられるとは限らない。実際の定義と照らし合わせて確認する必要がある。
- 表示できたトークン数（入力 / 出力）：実行ごとに異なるため、`[入力トークン数]` と `[出力トークン数]` として実行時に表示される。
例：
`uv run python -m app.ask "LoRAとは何ですか？"`
`[入力トークン数]` と `[出力トークン数]` に実行時の値が表示される。

## 宿題

- 取り組んだレベル：実装
- やったこと：SDKの `client.chats.create()` で1つのChatを作成し、各質問を同じChatの `send_message()` に渡すよう `app/ask.py` を改修した。Chatがユーザーとモデルの発言履歴を管理し、次の質問にもまとめて送る方式である。
- 結果：最初の質問への回答後も入力待ちになり、`exit` または `quit` を入力するまで同じChatで会話を続けられる。応答ごとに入力・出力トークン数も表示される。
- 気づき・疑問：会話履歴が蓄積されるため、後の質問では入力トークン数が増える。長い会話ではコンテキストウィンドウやトークン使用量への影響を確認する必要がある。
