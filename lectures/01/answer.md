## 宿題

- 取り組んだレベル：基礎
- やったこと：
  - `app/ask.py` に `--temperature` オプションを追加した。`types.GenerateContentConfig(temperature=...)` を `generate_content` の `config` に渡す。
  - temperature が API まで届いているかを確かめるため、範囲外の `--temperature 5` を渡した。400 エラー（`temperature must be in the range [0.0, 2.0]`）が返ることを確認した。
  - gemini-3.5-flash-lite で、次の2つの質問を temperature 0 / 0.8 / 2.0 の3通りで3回ずつ実行した（計18回）。
    1. 「LoRAとは何ですか？」
    2. 「AIエンジニアリング講座の宿題の３レベルについて教えて」
  - 参考として、gemini-3.8-flash でも「LoRAとは何ですか？」を temperature 未指定 / 0 / 0.5 / 0.8 で1回ずつ実行した。
- 結果：

  出力トークン数（gemini-3.5-flash-lite、3回分）

  | temperature | LoRAとは何ですか？ | 宿題の3レベル |
  |---|---|---|
  | 0 | 548 / 612 / 695（平均 約618） | 779 / 767 / 911（平均 約819） |
  | 0.8 | 729 / 623 / 682（平均 678） | 755 / 1104 / 781（平均 880） |
  | 2.0 | 614 / 605 / 492（平均 約570） | 824 / 868 / 893（平均 約862） |

  **共通**
  - temperature 0 でランダム性を最小にしても、3回とも内容と長さが違い、毎回同じ答えにはならなかった。
  - temperature の上限である 2.0 に設定しても文章は崩れず、LoRA の質問ではむしろ短い回答になった。

  **LoRA についての回答**
  - 0.8 では、たとえ話（ノート・付箋・バイパス回路）や、0 の回にはなかった情報（2021年にMicrosoftが発表したこと、破滅的忘却）が出力された。
  - 一方、0.8 では LoRA の利用例として Midjourney を挙げていた。Midjourney は利用者が LoRA を適用できるサービスではないため、これは誤りである。
  - 学習するパラメータの割合は、回ごとに「1万分の1程度」「数%以下」「1%未満」など表現が違った（LoRA の論文では、GPT-3 で約1万分の1とされている）。
  - gemini-3.8-flash は、最初の2回が 503（混雑）で失敗した。成功した回の出力は 732〜845 トークンだった。lite で見られた「メモランダム」「数テンMB」のような不自然な語は出なかった。また、通信技術の LoRa（Long Range）との区別を説明する回もあった（4回中2回）。

  **講座固有の質問についての回答**
  - どの temperature でも、全回が難易度の段階という誤った説明だった。揺れが見られたのは、言い回しと長さだけだった。
- 気づき・疑問：
  - temperature は API まで届いているのに、0 でも出力は揺れ、2.0 でも文章は崩れなかった。Google が temperature を非推奨にした影響で生成にほとんど効いていないのか、サーバー側の処理でもともと揺れが出るのかは、3回ずつの実験では区別できなかった。
  - temperature を変えても、「知らないことをもっともらしく答える」性質は変わらなかった。正しく答えさせるには、パラメータではなく、用語集などの情報を渡す仕組みが必要である。
  - 答えを知らない質問では、知っている質問に比べて、質問者に寄り添った（なれなれしい）口調になり、多弁になる傾向が見られた。temperature 2.0 では、出力トークン数が平均で約292多かった（862 対 570）。ただし質問の内容自体が違うため、長さの差がすべて「知らないこと」によるものとは言い切れない。
  - 数値のような細かい事実は回ごとに変わるので、LLM の回答をそのまま使うときは確認が必要である。
  - 範囲外の値を渡したときのエラー表示は「APIキーかモデル名に問題があります（400）」だったが、本当の原因は後ろの英文に書かれていた。`app/config.py` が 400 番台のエラーをまとめて同じ日本語で表示するためで、元のメッセージを読む大切さに気づいた。
