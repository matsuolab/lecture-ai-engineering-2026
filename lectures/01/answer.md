## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：
AIE2026（AIエンジニア育成講座などのプログラム）の宿題における「3レベル」という言葉は、一般的に**受講生のスキルや理解度、または課題の難易度に合わせて用意された3段階の課題（レベル1、レベル2、レベル3）**を指します。

- 用語集の正しい意味と比べて気づいたこと：用語集の定義は，「AIE2026の宿題の構成。「基礎（講義内容の確認）」「実装（自分でコードを書く）」「発展（調査や試行）」の3段階があり、どれか1つに取り組めばその回の宿題は完了」である．これに対し，モデルの回答は，3レベルを課題の難易度と定義しており，意味があっている．ただ，各レベルの定義（基礎は講義内容の確認，実装は自分でコードを書く，発展は調査や試行）までは回答できていない．これは本講座特有の定義であるため，モデルの回答としては妥当と考えられる．

- 表示できたトークン数（入力 / 出力）：[トークン数] 入力: 22, 出力: 583 (uv run python -m app.ask "AIE2026 の講座の宿題にある「3レベル」とは何ですか？ ")

## 宿題

- 取り組んだレベル：実装

- やったこと：
　app/ask.pyを改修し，会話履歴を保ったまま続けて質問できるようにした．
　ask.pyを，質問ごとに生成する方式から，同じチャットセッションで履歴を保つ対話形式に変更した．起動時の質問に回答後，続けて入力できる．各応答では入力・出力トークン数を表示し，exit，quit，q，終了で終了する．APIエラーと入力終了も処理する．
  
- 結果：
　前の質問・回答に関連する質問が投げられるようになった．
  1回目：「AIE2026 の講座の宿題にある「3レベル」とは何ですか？」
　2回目：AIの活用レベルの場合は3レベルはどうなりますか？

- 気づき・疑問：
