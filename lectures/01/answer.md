## 宿題

- 取り組んだレベル：基礎
- やったこと： 
  - "LoRAとは何ですか？" という質問を、gemini-3.1-flash-lite、gemini-3.5-flash-lite、gemini-3.6-flashの
    3つのモデルに対して送付し、リクエストを比較
    - $ AIE_MODEL=gemini-3.1-flash-lite uv run python -m app.ask "LoRAとは何ですか？"
    - $ AIE_MODEL=gemini-3.5-flash-lite uv run python -m app.ask "LoRAとは何ですか？"
    - $ AIE_MODEL=gemini-3.6-flash uv run python -m app.ask "LoRAとは何ですか？"
  
- 結果：
  - 同じ質問「LoRAとは何ですか？」に対して、3つのGeminiモデルは結論自体はほぼ同じだが、説明スタイル・対象読者・情報の粒度に違いがあった。
  - Gemini 3.1 Flash Lite
    - もっとも「入門記事」的かつ非常に直感的。特に以下の表現が目立った。
    - 「元のAIを改造せずに追加パーツをくっつける技術」
    - 「本の内容はそのままで付箋を貼る」
  - Gemini 3.5 Flash Lite
    - 3.1の説明をベースにしつつ、「ファインチューニングとの比較」を強化していた。
    - 構成は「従来」「LoRA」「メリット」という比較中心であった。
  - Gemini 3.6 Flash
    - 最も成熟した説明であった。
    - 「壊滅的忘却（Catastrophic Forgetting）」、「VRAMへの言及」、「活用事例が具体的」といった特徴あり
- 気づき・疑問：
  - 3モデルとも、LoRAの核心部分である「低ランク分解を利用して重み更新を近似する」について説明はしていなかった。
  - 調べた範囲では、Flash 系モデルが「正確さより理解しやすさを優先した回答生成」をしているため、こういった傾向があるとのこと
  - 古いモデルとはいっても、わかりやすさを重視する場合には、十分な品質が得られるケースがあるのは留意すべきポイントだと感じた
