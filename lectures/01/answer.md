# 第1回 解答

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：
  gemini-3.5-flash-lite に「AIE2026 の講座の宿題にある『3レベル』とは何ですか？」と質問した。モデルは講座の内容を知らず、「AIE2026（おそらく『AIエンジニア育成プログラム2026』などを指していると思われます）」と推測を述べたうえで、一般的な講座にある「レベル1（基礎）／レベル2（応用）／レベル3（発展）の3段階の難易度」という構成で答えた。「分からない」とは言わず、各レベルの対象者や内容までもっともらしく説明していた。
- 用語集の正しい意味と比べて気づいたこと：
  この講座の宿題の3レベルは「基礎・実装・発展」で、内容は、基礎＝同じ質問を繰り返しモデルや temperature を変えて回答の違いをまとめる、実装＝app/ask.py を改修して会話履歴を保ったまま質問できるようにする、発展＝応答時間とトークン数を計測して複数モデルで比較する、というもの。モデルの答えは「基礎」「発展」という名前が一部重なったが、中身は別物（モデルは「応用」としていた）で、講座固有の内容は合っていなかった。それでも確信のある口調で答えており、知らないことでも自信を持って答えることがあると分かった。
- 表示できたトークン数（入力 / 出力）：
  入力 21 / 出力 518（上記の質問、gemini-3.5-flash-lite）

## 宿題

- 取り組んだレベル：基礎
- やったこと：
  同じ質問「LoRA とは何ですか？」を、AIE_MODEL 環境変数でモデルを変えて、それぞれ3回ずつ実行し、回答の違いを比べた。使ったモデルは gemini-3.5-flash-lite と gemini-3.8-flash。temperature は変更していない。
- 結果：
  出力トークン数は、gemini-3.5-flash-lite が 659 / 573 / 621、gemini-3.8-flash が 848 / 809 / 842 で、3.8-flash の方が約3割長かった。入力トークン数はどちらも7で同じだった。
  flash-lite の3回は、いずれも「元のモデルは固定し、付箋のような小さな追加部分だけを学習する」という説明にとどまり、「低ランク」の意味（重みの更新量を小さな行列で表すこと）には触れなかった。また、LoRA ファイルのサイズが「数MB〜数十MB」（1回目・3回目）と「数MB〜数百MB」（2回目）で食い違った。
  3.8-flash の3回は、いずれも「低ランク」や行列分解に触れ、「2021年にMicrosoftの研究者が提案」という具体的な情報が3回とも出た。2回目だけ、学習後にモデルと合体（マージ）できて推論速度が落ちない点に言及した。
  どちらのモデルも、構成は大筋で同じだが、例え話や言及する内容が毎回変わった。flash-lite は付箋のほか、2回目に教科書の例え話が加わった。3.8-flash は1・2回目が百科事典と付箋、3回目はDLC・カセットと高解像度の絵の圧縮という例えだった。
  3.8-flash は体感で応答が遅かった（時間は計測していない）。エラー（429, 503 など）は出なかった。
- 気づき・疑問：
  上位モデルの方が、説明が深く、具体的な事実も増える傾向があった。一方、同じモデルでも実行ごとに構成・例え・細部（数値など）が変わるため、出力をそのまま事実として使うのは危険だと感じた。ファイルサイズなど、回ごとに食い違う数値の正しさは自分では検証していない。
  今回は3回ずつでサンプルが少なく、傾向は断定できない。temperature を変えたときに揺れがどう変わるかや、応答時間の計測は試せていないので、今後確かめたい。
