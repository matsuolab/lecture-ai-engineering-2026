２．実装

　app/ask.py を改修し、会話履歴を保ったまま続けて質問できるようにした。
　改修後のapp/ask.py は以下のとおり。

------------------------------------------------------------------------------
import os
import sys
DEFAULT_QUESTION = "AIE2026の講座の宿題にある「3レベル」とは何ですか？"


from google import genai
from google.genai import types


def main():
    # コマンドライン引数から質問を取得
    if len(sys.argv) < 2:
        print("Usage: uv run python -m app.ask '<question>'")
        sys.exit(1)
    
    prompt = sys.argv[1]
    
    # モデル名の取得（環境変数 AIE_MODEL があればそれを使用、なければデフォルト）
    model_name = os.environ.get("AIE_MODEL", "gemini-2.5-flash") # 指定モデル
    
    # GenAI クライアントの初期化
    client = genai.Client()

    # 【実装レベルのポイント】
    # チャットセッションを作成し、履歴を保持できるようにする
    # ※ system_instruction や config もここで
    chat = client.chats.create(model=model_name)

    # 質問を送信してレスポンスを取得
    response = chat.send_message(prompt)

    # 結果の出力（トークン数などもここで表示）
    print(response.text)
    
    # トークン数を表示させる場合は以下メタデータも確認できます
    if hasattr(response, "usage_metadata") and response.usage_metadata:
        print(f"\n[Token Usage] Input: {response.usage_metadata.prompt_token_count}, Output: {response.usage_metadata.candidates_token_count}")

if __name__ == "__main__":
    main()

### LoRAの主なメリット

1.  **圧倒的な省リソース（低コスト）**
    学習させるパラメータの量が元の数％（あるいは0.1%以下）で済むため、個人のパソコン（一般的なグラフィックボードを搭載したPC）でも学習が可能です。

3.  **簡単に切り替えられる**
    ベースとなるAIモデルは1つだけ用意し、その上に「アニメ風にするLoRA」「特定の人物を描くLoRA」「特定の口調にするLoRA」などをパズルのように**付け替えるだけで、AIの性格や出力スタイルを自由に変更**できます。

### 1. 従来の課題と、LoRAの解決策
AIに特定のキャラクターを描かせたり、特定の専門知識を覚えさせたりするには「追加学習」が必要です。

*   **従来の方法：**

### 1. わかりやすいイメージ（例え話）

従来の追加学習は、**「分厚い百科事典（基本モデル）のすべてのページに直接ペンで書き込みをして修正する」**ようなものでした。これには膨大な時間と高性能なコンピューター、そして巨大な保存容量が必要でした。

一方、LoRAは、**「百科事典の上から透明なシート（LoRA）を重ねて、変更したい部分だけシートにメモする」**ような仕組みです。
* 本体の百科事典は書き換えない（固定する）
* メモ（LoRA）だけを取り替えれば、別の専門書に早変わりする
* メモだけなので、データサイズが非常に小さい

### 2. LoRAの大きなメリット

1. **データ容量が圧倒的に小さい**
   * 元のAIモデルが数GB～数十GBあるのに対し、LoRAのファイルサイズは**数MB～数百MB程度**で済みます。配布やダウンロードが非常に簡単です。
2. **少ないパソコン性能（VRAM）で学習できる**
   * 本体の数千億個あるパラメーターを凍結し、ごく一部（数％以下）の追加パラメーターだけを学習させるため、一般家庭向けのゲーミングPC（GPU）でも追加学習が可能です。
3. **着脱や組み合わせが自由**
   * 「画風LoRA」＋「特定キャラクターLoRA」のように、複数のLoRAを同時に重ねがけして適用することができます。また、不要になったらLoRAを外すだけで元のモデルに戻せます。

### 3. 主な活用例

* **画像生成AI（Stable Diffusionなど）**
  * 特定のアニメキャラクターの見た目を正確に出す
  * 特定のイラストレーターの絵柄や、実写の特定ポーズを再現する
  * 特定の衣装や背景のスタイルを固定する
* **テキスト生成AI（LLM）**
  * 一般的なAIに、社内文書や特定の法律知識を追加で覚えさせる
  * ツンデレ風や執事風など、特定の「口調・キャラクター」を持たせる
  * プログラミング言語の特定フレームワークに特化させる

### まとめ

LoRAは、**「巨大なAIを、誰でも・手軽に・自分好みにカスタマイズできるようにした画期的な技術」**です。現在のアマチュアからプロまでのAIカスタマイズにおいて、標準的な手法として広く使われています。

*(※なお、無線通信の規格にも「LoRa (Long Range)」という同名のものがありますが、AIの文脈であれば上記を指します)*
