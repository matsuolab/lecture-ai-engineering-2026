gemini-3.5-flash-lite では3回とも回答を取得できた。LLMについて「Large Language Modelの略で、大量のテキストを学習し、自然言語を理解・生成するAI」という基本的な説明は共通していた。
一方で、3回の回答は完全に同じではなく、「できること」「大規模と呼ばれる理由」「得意・苦手」「注目される理由」など、取り上げる内容や説明の詳しさが異なっていた。
gemini-3.8-flash でも同じ質問を3回実行したが、3回とも503エラーとなり、回答内容を取得することはできなかった。

# 用語集の正しい意味と比べて気づいたこと：

gemini-3.5-flash-lite の回答では、「Large Language Model」「自然言語を扱うAI」といったLLMの基本的な意味は3回とも共通していた。

# 取り組んだレベル：基礎

# やったこと：

AIE_MODEL 環境変数を使って、gemini-3.5-flash-lite と gemini-3.8-flash を切り替えた。
両モデルに対して「LLMとは何ですか？」という同じ質問を3回ずつ実行し、回答内容とトークン数の違いを比較した。
response.usage_metadata から入力トークン数と出力トークン数を表示する処理を追加した。

# 結果：

gemini-3.5-flash-lite は3回とも正常に回答を取得できた。
入力トークン数は3回とも7で共通だったが、出力トークン数は413、495、533と毎回異なった。
gemini-3.5-flash-lite の回答は、LLMの基本的な定義については共通していたものの、回答の詳しさや構成、取り上げる項目には違いがあった。
gemini-3.8-flash は同じ質問を3回実行したが、3回とも「モデルが混み合っています（503）」となり、回答を取得できなかった。
そのため、今回はgemini-3.5-flash-liteとgemini-3.8-flashの回答内容そのものを比較するところまではできなかった。

# 気づき・疑問：

同じ質問を同じモデルに与えても、毎回同じ回答になるわけではなく、出力トークン数や回答の構成が変わることが分かった。
gemini-3.5-flash-liteでは3回連続で回答を取得できた一方、gemini-3.8-flashでは3回とも503となった。
今回は3.8の回答を取得できなかったため、モデルの性能や回答品質の優劣については判断できない。
モデルを比較するときは回答の内容だけではなく、正常に利用できるかどうかも実際の利用上では重要だと感じた。
