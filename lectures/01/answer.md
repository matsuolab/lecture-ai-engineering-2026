## 宿題

- 取り組んだレベル：発展
- やったこと：応答時間を測るプログラムを作成して、"LoRAとは何ですか？"という質問をgemini-4-argon、gemini-3.8-flash、gemini-3.5-flash-lite、gemini-3.1-flash-liteの４モデルを使い、応答時間、トークン数、出力結果を比較した。
- 結果：outputのトークン数と応答時間が、geminiのモデルの性能を上げるにつれて増えていった。（しかし全て750前後であった。）またgemini-4-argonについてはレート制限に達したため、使用することができなかった。応答の構成はほとんど変わらなかったがgemini-3.8-flashだけ「まとめ」の項目の代わりに補足が書いてあった。
- 気づき・疑問：https://qiita.com/shikuno_dev/items/f5766300ae30b097917b　API レート制限とは
を参照し、レート制限にはトークン数が関係していることが関係していることが分かった。このことから、「geminiのモデルの性能を上げるにつれて増えていった」ことより、gemini-4-argonのトークン数が高いことが分かる。またGemini API の使用状況を見ると分かる通り高性能になるおほど出力トークン数が増えていることがわかるため、制限がかかり時間も長時間かかるようになっていることが分かった。実際応答時間はgemini-3.8-flasでは200秒以上かかってしまった。このことより、有料版では時間当たりのトークン数の制限が緩和され、より多量の出力を可能ににしていると気づいた。
