# モデルによる応答の違い

`terminal_log.md` に記録された実行結果を、回答内容と実行状況に分けて整理したメモです。

## 比較対象と実行結果

| ログ上のモデル名 | 質問 | 結果 |
|---|---|---|
| `gemini-3.5-flash-lite` | 「LoRAとは何ですか？」 | 回答あり |
| `gemini-3.5-flash-lite` | 「AIE2026の講座の宿題にある『3レベル』とは何ですか？」 | 回答あり |
| `gemini-3.5-flash` | 「LoRAとは何ですか？」 | 回答あり（出力732 tokens） |
| `gemini-3-flash-preview` | 「LoRAとは何ですか？」 | 回答あり（出力841 tokens） |

モデル間で同じ質問を比較できるのはLoRAの質問だけです。「3レベル」への回答は `gemini-3.5-flash-lite` のみなので、他モデルとの比較はできません。

## LoRAへの回答の違い

### `gemini-3.5-flash-lite`

- 「付箋」や「着せ替え」の比喩を使い、読みやすく親しみやすい説明です。
- 追加ファイルの小ささ、学習の軽さ、画像生成AIでの活用を中心に説明しています。
- LLMと画像生成AIの説明が少し混ざっており、技術的な仕組みや適用条件は簡略化されています。
- 「短時間で学習」「自由自在に切り替え」など、条件によって異なる点を断定的に表現しています。

### `gemini-3.5-flash`

- 「Low-Rank Adaptation」の展開、低ランク行列、元モデルを固定して差分を学習する点を説明しており、3回答の中では仕組みの説明が比較的明確です。
- 画像生成とLLMの両方の用途を挙げ、見出しで整理しています。
- 出力は732 tokensで、`gemini-3-flash-preview` の回答（841 tokens）より短いです。
- 「一般家庭用GPUでも可能」「専門知識を学習」などは、モデルやデータ、学習環境に依存します。LoRAだけで知識の正確な追加が保証されるわけではありません。

### `gemini-3-flash-preview`

- 例え話、技術的説明、メリット、用途まで扱い、比較対象では最も詳しい回答です（841 tokens）。
- 「2つの小さな行列」という低ランク近似の説明や、QLoRAへの言及があります。
- 一方で「すべて解決」「一瞬で終わる」「魔法のよう」といった誇張があり、学習コスト・時間・効果を実際より単純に見せるおそれがあります。
- パラメータ数を「1,000分の1〜10,000分の1」とする箇所など、条件を伴う数値は出典や前提の確認が必要です。

## 「3レベル」への回答

`gemini-3.5-flash-lite` は、「初級・中級・上級」の一般的な段階を想定して説明しました。ただし、質問にあるAIE2026の宿題の定義を確認したものではなく、「通常はそういう意味」と推測した回答です。特定講座の用語としては根拠不足で、教材や宿題の案内に照らして確認が必要です。

## 実行上の注意

- `AIE_MODEL=gemini-3.5-flash` を単独で入力した後の実行では、ログ上のモデル名は `gemini-3.5-flash-lite` のままでした。環境変数をコマンドに渡す場合は、ログで実際に選択された `[model]` を確認してください。後の `AIE_MODEL=... uv run ...` 形式では指定したモデル名が表示されています。
- `gemini-3.5-flash` を使った「3レベル」への実行は、応答待ちの後に `Ctrl+C` で中断されており、回答比較の材料にはなりません。
- `gemini-3.1-flash` と `gemini-3-flash` は404（モデルが見つからない／`generateContent` 非対応）、`gemini-2.5-flash` は新規ユーザーには利用できない旨のエラーでした。これらは回答品質の比較対象ではありません。

## まとめ

- 回答の傾向として、`gemini-3.5-flash-lite` は簡潔で親しみやすく、`gemini-3.5-flash` は比較的要点を絞って仕組みを説明し、`gemini-3-flash-preview` は詳しい一方で強い断定や誇張が目立ちます。
- このログは各モデルの回答が1回ずつで、同じ条件の質問も1種類だけです。したがって、モデル全体の優劣を示すものではなく、今回の出力の違いとして読むのが適切です。
- 特に講座固有の質問や数値・性能の主張は、回答の流暢さとは別に、教材や信頼できる資料で事実確認する必要があります。
