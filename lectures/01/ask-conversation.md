# `app.ask` の会話履歴と使い方

## 実装内容

`app/ask.py` は、Gemini に1回だけ質問するスクリプトから、会話履歴を保って続けて質問できる対話スクリプトに変更しました。

- 起動時に Gemini の `Chat` を1つ作成し、質問のたびに同じチャットの `send_message()` を呼び出します。これにより、それまでの質問と回答を踏まえた応答ができます。
- 最初の質問はコマンドライン引数で指定できます。省略した場合は、講座の宿題にある「3レベル」についての既定の質問から始めます。
- 回答後、続きの質問を入力できます。空行を入力するか入力が終了すると、対話を終了します。
- 各回答の入力・出力トークン数を表示します。API エラーは既存の日本語メッセージに変換して表示します。
- チャット履歴は実行中のメモリ上に保持されます。プログラムを終了して再起動した場合、前の実行の会話は引き継がれません。
- ツール検索は行いません。講座固有の用語を質問した場合、用語集を使わずに回答します。

## 使い方

リポジトリのルートで、最初の質問を指定して実行します。

```bash
uv run python -m app.ask "LoRAとは何ですか？"
```

回答が表示されたら、同じ会話の続きとして質問を入力します。たとえば、次のように質問できます。

```text
[model] gemini-3.5-flash-lite
[質問] LoRAとは何ですか？

[tokens] input=... output=...
（回答）

続けて質問してください（終了するには空行）: QLoRAとの違いは何ですか？
[質問] QLoRAとの違いは何ですか？
...
```

もう続けない場合は、入力せずに Enter キーを押して空行にします。ターミナルから入力が終了した場合も対話を終了します。

質問を指定せずに起動すると、既定の質問から始まります。

```bash
uv run python -m app.ask
```

## 実行前の設定

Gemini API キーを環境変数 `GEMINI_API_KEY` に設定してください。API キーはソースコードや質問文に書かないでください。使用するモデルは `AIE_MODEL` で変更でき、省略時は `gemini-3.5-flash-lite` が使われます。

```bash
AIE_MODEL=gemini-3.5-flash uv run python -m app.ask "LoRAとは何ですか？"
```
